# EcoLearn Pro - Complete Gamified Sustainability Education Platform

A complete frontend project for schools/colleges. Runs offline using HTML, CSS, JavaScript and localStorage.

## Features
- **Smart Digital Dustbin & Scanner (`scan.html`)**:
  - Scan ID on Bin via Camera QR Code or 1-tap NFC simulation.
  - Source segregation selection (Plastic, Paper, Wet, Metal, E-Waste).
  - Visual motorized compartment unlock and lid-opening animation.
  - IoT sensor verification (Load cell weight measurement & ultrasonic fill level).
  - Instant Eco-Coins & XP rewards credited to student wallet.
  - Two-tier Redemption Hub:
    - **College Redemption**: Canteen meal discounts, Stationery store kit, Library fine waivers, Campus cafe.
    - **Public Place Redemption**: Metro & railway subsidies, City Eco-Park passes, Civic micro-payments & electric bus transit.
  - Authorities Backend Dashboard for real-time fill level monitoring & AI waste collection route optimization.
- **Student dashboard (`dashboard.html`)** with quick-scan banner and progress metrics
- **Landing page (`index.html`)**
- **Signup/Login demo**
- **Lessons with XP rewards (`lessons.html`)**
- **Quiz engine with scoring (`quiz.html`)**
- **Real-world challenge submission (`challenges.html`)**
- **Teacher review/approval panel (`teacher.html`)**
- **Leaderboard (`leaderboard.html`)**
- **Badges and profile (`profile.html`)**
- **Certificate page (`certificate.html`)** with print/save as PDF

## How to run
Open `index.html` or `scan.html` in any browser. No backend needed.

Demo login: any email/password works.
